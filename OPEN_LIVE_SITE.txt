Core Law Firm India - Landing Page

Live website (works on mobile, tablet, and desktop):
https://core-law-firm-landing.vercel.app

What is in this folder
- index.html - Vite entry shell. The website is built from the React source in src/ into dist/.
- src/ - React components, styles, page copy, and artwork.
- public/ - favicon.
- assets/ - logo, artwork, and responsive screenshots for reference.

Google Drive
Google Drive stores and previews files; it does not host websites or run build tools. Open the live
link above on any device to see the working page.

To share this folder from Drive:
1. Upload this whole folder to Google Drive.
2. Right-click the folder and choose Share.
3. Choose who can view it, then copy the link.
4. Include the live website link above so people can open the actual page.

Local development
Install dependencies with "npm install", then run "npm run dev" or "npm run build".
